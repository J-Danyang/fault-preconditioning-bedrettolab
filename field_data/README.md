# Field data (Fig. 1)

The FEAR-1 field data are not redistributed here. Get them from the original archives and save them
in this folder with the file names below:

| File | Source |
|---|---|
| `FEAR1_seismicity.csv` | FEAR-1 seismicity catalog, ETH Research Collection, https://doi.org/10.3929/ethz-b-000743181 (currently under embargo) |
| `FEAR1_injection_flow_rate.csv`, `FEAR1_pressure_BFE05.csv` | FEAR-1 injection flow rate and injection pressure (borehole BFE05), hydraulic data, ETH Research Collection, (DOI to be added) |

The FEAR-1 data report (in preparation): https://doi.org/10.3929/ethz-c-000783939.
Seismicity data from the Mzero experiments: https://doi.org/10.3929/ethz-c-000789401.
